# Building Materials Transactions Analysis

##  Project Overview

This project analyzes **building materials transaction data** to identify sales patterns, product performance, customer behavior, and business trends. The project uses data cleaning, exploratory data analysis, and business analytics techniques to transform raw transaction data into actionable insights.

The analysis is designed as a **Business Analytics portfolio project**, demonstrating the use of data preparation, descriptive analytics, and data-driven decision-making.

##  Objectives

- Analyze building materials transaction patterns
- Identify top-performing products and categories
- Understand sales and transaction trends
- Examine customer and regional purchasing behavior
- Detect potential patterns and anomalies in transaction data
- Generate insights that can support inventory, pricing, and sales decisions

## Dataset

The repository contains:

- `building_materials_transactions_Cleaned.csv` — cleaned transaction dataset used for analysis
- `data_dictionary_materials.csv` — data dictionary describing the dataset's variables and fields

The cleaned dataset contains structured transaction-level information related to building materials sales.

##  Data Preparation

The data preparation process includes:

1. Checking the dataset structure and data types
2. Identifying missing values
3. Handling duplicate records
4. Converting variables into appropriate data types
5. Standardizing categorical fields
6. Checking for inconsistent or invalid values
7. Preparing the cleaned dataset for analysis

## Analysis Areas

The project explores several business questions, including:

- Which building materials generate the highest transaction value?
- Which products have the highest transaction volume?
- How do transactions vary across different periods?
- Which customer or market segments contribute the most?
- Are there noticeable regional or category-level differences?
- What trends could influence inventory and sales planning?

##  Business Applications

The insights from this analysis can support:

- **Inventory Management** — identifying high-demand materials
- **Sales Planning** — understanding product and transaction trends
- **Product Management** — evaluating category performance
- **Customer Analysis** — identifying purchasing patterns
- **Revenue Optimization** — identifying areas of stronger commercial performance
- **Business Forecasting** — using historical patterns to support future planning

##  How to Run

Clone the repository:

```bash
git clone https://github.com/your-username/building-materials-analytics.git
```

Navigate to the project directory:

```bash
cd building-materials-analytics
```

Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open the analysis notebook and run the cells sequentially.
